## Instrucciones de ejecución

1. Descomprimir tarea.
2. Ejecutar `cmake -S . -B build`.
3. Crear archivos binarios usando `cmake --build build`.
4. Ejecutar archivo main que genera los resultados de la experimentación `build/src/main` (genera un `csv`)
5. Crear carpeta para guardar imagenes `mkdir img`
6. Ejecutar archivo de python `intVSdouble.py` para generar las imagenes en base al `csv` obtenido (se necesita instalar las librerías indicadas en `requirements.txt`)
7. Para ejecutar archivo con tests de la tarea pasada escribir en la terminal `./build/test/tests`.
